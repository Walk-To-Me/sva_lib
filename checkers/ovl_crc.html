ovl_crc — CRC 参考计算与比较

位编码、互斥与数据完整性 OVL V2 接口

内部计算 CRC，并在 compare 触发时与输入校验值比较。

语义参数端口例子FormalSVA 属性来源

1. 检查语义与触发时机

initialize 设置内部初值；valid 控制数据装载。crc_enable 决定从 crc 专用端口还是 test_expr 数据流取待比较 CRC；还支持位序、字节序、反转、反相及锁存。

多项式正确还不够：initial_value、反射/端序、最终反相和 compare/valid 时序必须一致；先用 golden vector 标定。

以下说明以随包 SVA 实现为重点。复位后的首次有效采样、历史状态有效位以及 generate 条件会影响检查起点；属性原文与完整源码可在本页下方对照。

2. 完整参数表

按 wrapper 声明顺序列出。默认表达式逐字取自源码；宏的最终值可被编译选项或用户头文件覆盖。标为内部/派生参数的条目不建议手动覆盖。

参数源码默认值作用与配置注意
severity_level`OVL_SEVERITY_DEFAULT失败报告的严重级别：OVL_FATAL、OVL_ERROR、OVL_WARNING、OVL_INFO；不是改变逻辑正确性的开关。
width1被检查数据/向量的位宽；对于 arbiter 是通道数，对于 CRC 是输入分片位宽。
data_width0存储器数据宽度；CRC 中为完整数据项宽度，0 表示采用输入 width。
crc_width5CRC 寄存器与校验值位宽。
crc_enable01 从 crc 专用输入取比较值；0 从 test_expr 数据流取 CRC。
crc_latch_enable0是否使用 crc_latch 将内部结果锁存后再比较。
polynomial5自定义 CRC 生成多项式编码；需按 LRM 的最高项约定填写。
standard_polynomial0选择内建标准多项式编码；非默认配置应核对 LRM 列表和源码 case。
initial_value0initialize 时装载到 CRC 参考寄存器的初值。
lsb_first0数据项的位输入顺序配置。
big_endian0数据项字节序配置。
reverse_endian0CRC 比较值端序反转配置。
invert0CRC 结果反相配置。
combinational0选择组合 CRC 检查行为；与逐拍累计消息模式不同。
property_type`OVL_PROPERTY_DEFAULT选择 OVL_ASSERT、OVL_ASSUME、OVL_IGNORE 或二态变体；只有支持的后端才把 ASSUME 实现为形式约束。不要把 DUT 要求改为 assume 来消除失败。
msg`OVL_MSG_DEFAULT实例的诊断文本，建议包含被检查接口与需求名称。
coverage_level`OVL_COVER_DEFAULT覆盖层级位掩码；NONE=0、SANITY=1、BASIC=2、CORNER=4、STATISTIC=8、ALL=15。同时受 OVL_COVER_ON 控制。
clock_edge`OVL_CLOCK_EDGE_DEFAULTchecker 的时钟有效沿：OVL_POSEDGE、OVL_NEGEDGE 等；各后端支持情况需核对。
reset_polarity`OVL_RESET_POLARITY_DEFAULT复位有效电平：OVL_ACTIVE_LOW 或 OVL_ACTIVE_HIGH；不要因端口名为 reset 就默认高有效。
gating_type`OVL_GATING_TYPE_DEFAULTOVL_GATE_CLOCK 暂停时钟采样；OVL_GATE_RESET 用 enable 参与复位；OVL_NONE 不使用门控。暂停与清空历史不是同一语义。
assert_name"OVL_CRC"内部诊断标识。源码注明不应修改。

3. 完整端口表

端口方向位宽表达式连接含义
clockinput1 bit采样时钟；有效沿由 clock_edge 决定。
resetinput1 bitchecker 复位输入；有效电平由 reset_polarity 决定。
enableinput1 bitOVL V2 门控输入，意义由 gating_type 决定；不一定只是 disable iff。
test_exprinput[width-1:0]被检查的表达式/数据，具体触发与比较规则见本页。
initializeinput1 bit初始化 CRC 参考状态。
crcinput[crc_width-1:0]crc_enable=1 时使用的外部 CRC 比较值。
compareinput1 bit启动 CRC 比较。
validinput1 bit数据流当前片段有效。
crc_latchinput1 bit启用锁存模式时锁存内部 CRC。
fireoutput[`OVL_FIRE_WIDTH-1 : 0]事件汇总输出；部分 wrapper 在 SVA 分支将其绑零，见本页实现提示。

4. 合法与违例场景

合法 / 期望覆盖场景

输入已知消息，并提供按完全相同 CRC 约定计算的校验码。

违例 / 覆盖缺口场景

数据不变而将预期 CRC 任意翻转一位。

示例中的周期指 checker 的有效采样沿；“变化”通常指相邻采样值变化。场景是语义说明，不代表下面保留默认参数的模板已配置成该场景。

命名参数 / 命名端口连接模板

这是接线片段，不是独立可运行的 testbench。需声明并驱动信号，设置实际宽度、复位极性、延迟及检查开关，再将 wrapper 加入编译列表。下载 SV 模板。

5. Formal 接入与判读

多项式正确还不够：initial_value、反射/端序、最终反相和 compare/valid 时序必须一致；先用 golden vector 标定。

  • 验证 DUT 的要求使用 OVL_ASSERT；只有外部环境协议才适合作为 OVL_ASSUME。先检查 elaboration 后生成的属性数量与类型。
  • 复位应初始化 checker 的历史状态和参考模型；不要永久拉住复位或 enable=0。确认触发事件可达，避免 antecedent 永远为假的空证明。
  • 将安全断言结果、超时/未决结果与 cover 可达性分别记录。仿真跑过若干波形不等于形式证明。

此 wrapper 的 SVA 分支将 fire 绑为 0。不能用 fire==0 证明检查通过；必须读取工具中的原生 assert/assume/cover 结果。

更多复位、门控、X/Z 与编译宏说明见 公共接入指南。本页没有声称所有配置均在 VC Formal 上经过编译或证明。

OVL_CRC_CHECK_P
property OVL_CRC_CHECK_P;
  @(posedge clock)
    disable iff (`OVL_RESET_SIGNAL != 1'b1)
      (crc_check_fire_combo == 1'b0);
  endproperty
OVL_CRC_XZ_IN_TEST_EXPR_P
property OVL_CRC_XZ_IN_TEST_EXPR_P;
  @(posedge clock)
    disable iff (`OVL_RESET_SIGNAL != 1'b1)
      (!($isunknown(test_expr)));
  endproperty
