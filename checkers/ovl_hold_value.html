ovl_hold_value — 指定值的驻留时间

周期、窗口与稳定性 OVL V2 接口

test_expr 变化到与 value 相等时，检查该值保持的时间。

语义参数端口例子FormalSVA 属性来源

1. 检查语义与触发时机

min/max 配置允许最短保持与最长退出；min=max=0 的默认配置要求下一拍离开该值。max=0 且 min>0 表示仅最短保持约束。 首个有效检查周期若匹配目标也会启动。非零 min/max 的重复区间在启动之后计算，和 next_state 包含进入拍的驻留长度不同。

名称容易让人误以为默认永久保持；实际默认要求下一拍变化。value 是输入，可动态变化。

以下说明以随包 SVA 实现为重点。复位后的首次有效采样、历史状态有效位以及 generate 条件会影响检查起点；属性原文与完整源码可在本页下方对照。

参数源码默认值作用与配置注意
severity_level`OVL_SEVERITY_DEFAULT失败报告的严重级别：OVL_FATAL、OVL_ERROR、OVL_WARNING、OVL_INFO；不是改变逻辑正确性的开关。

max0本 checker 的最大数值/数量/步长/驻留参数；不能跨 checker 统一把 0 当成关闭。
width2被检查数据/向量的位宽；对于 arbiter 是通道数，对于 CRC 是输入分片位宽。
property_type`OVL_PROPERTY_DEFAULT选择 OVL_ASSERT、OVL_ASSUME、OVL_IGNORE 或二态变体；只有支持的后端才把 ASSUME 实现为形式约束。不要把 DUT 要求改为 assume 来消除失败。
msg`OVL_MSG_DEFAULT实例的诊断文本，建议包含被检查接口与需求名称。
coverage_level`OVL_COVER_DEFAULT覆盖层级位掩码；NONE=0、SANITY=1、BASIC=2、CORNER=4、STATISTIC=8、ALL=15。同时受 OVL_COVER_ON 控制。
clock_edge`OVL_CLOCK_EDGE_DEFAULTchecker 的时钟有效沿：OVL_POSEDGE、OVL_NEGEDGE 等；各后端支持情况需核对。
reset_polarity`OVL_RESET_POLARITY_DEFAULT复位有效电平：OVL_ACTIVE_LOW 或 OVL_ACTIVE_HIGH；不要因端口名为 reset 就默认高有效。
gating_type`OVL_GATING_TYPE_DEFAULTOVL_GATE_CLOCK 暂停时钟采样；OVL_GATE_RESET 用 enable 参与复位；OVL_NONE 不使用门控。暂停与清空历史不是同一语义。
assert_name"OVL_HOLD_VALUE"内部诊断标识。源码注明不应修改。

5. Formal 接入与判读

名称容易让人误以为默认永久保持；实际默认要求下一拍变化。value 是输入，可动态变化。

  • 验证 DUT 的要求使用 OVL_ASSERT；只有外部环境协议才适合作为 OVL_ASSUME。先检查 elaboration 后生成的属性数量与类型。
  • 复位应初始化 checker 的历史状态和参考模型；不要永久拉住复位或 enable=0。确认触发事件可达，避免 antecedent 永远为假的空证明。
  • 将安全断言结果、超时/未决结果与 cover 可达性分别记录。仿真跑过若干波形不等于形式证明。

此 wrapper 的 SVA 分支将 fire 绑为 0。不能用 fire==0 证明检查通过；必须读取工具中的原生 assert/assume/cover 结果。

更多复位、门控、X/Z 与编译宏说明见 公共接入指南。本页没有声称所有配置均在 VC Formal 上经过编译或证明。

6. 属性、诊断与覆盖

下面是源码中的命名 property 定义，包含宏分支；同名属性可在互斥 generate 分支中出现。它们不是“全部同时启用”的断言清单。实际启用条件、参考状态更新及 assert/assume 实例请看完整源码。

OVL_HOLD_VALUE_CASE1_P
property OVL_HOLD_VALUE_CASE1_P;
    @(posedge clk)
      disable iff(`OVL_RESET_SIGNAL != 1'b1)
        ( ( !$stable( test_expr) || sva_checker_time_0) &&
           ( test_expr == value)) |=>
             ( !$stable( test_expr));
  endproperty
OVL_HOLD_VALUE_CASE2_P
property OVL_HOLD_VALUE_CASE2_P;
    @(posedge clk)
      disable iff(`OVL_RESET_SIGNAL != 1'b1)
        ( ( !$stable( test_expr) || sva_checker_time_0) &&
           ( test_expr == value)) |=>
          ( ( !$stable( test_expr)) or
            ( ( test_expr == value)[*1:(max > 0 ? max : 1)] ##1 (!$stable( test_expr))));
  endproperty
OVL_HOLD_VALUE_CASE3_P
property OVL_HOLD_VALUE_CASE3_P;
    @(posedge clk)
      disable iff(`OVL_RESET_SIGNAL != 1'b1)
        ( ( !$stable( test_expr) || sva_checker_time_0) &&
           ( test_expr == value)) |=>
          ( ( test_expr == value)[*min:(max >= min ? max : min)] ##1 (!$stable( test_expr)));
  endproperty
OVL_HOLD_VALUE_CASE4_P
property OVL_HOLD_VALUE_CASE4_P;
    @(posedge clk)
      disable iff(`OVL_RESET_SIGNAL != 1'b1)
        ( ( !$stable( test_expr) || sva_checker_time_0) &&
           ( test_expr == value)) |=>
          ( ( test_expr == value)[*min:$] ##1 !$stable( test_expr));
  endproperty
OVL_HOLD_VALUE_XZ_ON_TEST_EXPR_P
property OVL_HOLD_VALUE_XZ_ON_TEST_EXPR_P;
    @(posedge clk)
    disable iff (`OVL_RESET_SIGNAL != 1'b1)
    (!($isunknown(test_expr)));
    endproperty
OVL_HOLD_VALUE_XZ_ON_VALUE_P
property OVL_HOLD_VALUE_XZ_ON_VALUE_P;
    @(posedge clk)
    disable iff (`OVL_RESET_SIGNAL != 1'b1)
    (!($isunknown(value)));
    endproperty

原始失败诊断文本

以下文本便于与工具报告交叉查找，触发条件见上面的对应属性和源码分支。

  • A match occurred and the expression had the same value in the next cycle
  • A match occurred and the expression held the same value for the next `max' cycles
  • A match occurred and the expression changed value before the event window or held the same value through the event window
  • A match occurred and the expression changed value before the event window opened
  • test_expr contains X or Z
  • value contains X or Z

  • cover_hold_value_for_min_cks
  • cover_hold_value_for_max_cks
