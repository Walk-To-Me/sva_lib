ovl_multiport_fifo — 多端口 FIFO scoreboard

FIFO、栈与存储器 OVL V2 接口

检查每拍多路入队/出队的队列容量、可选标志和数据顺序。

语义参数端口例子FormalSVA 属性来源

1. 检查语义与触发时机

enq/deq 是端口有效位掩码；同拍有效端口按低索引到高索引排列，数据分片同序。value_check/full_check/empty_check 默认均为 0，必须按目标显式开启。

不要将位掩码与 fifo_index 的二进制数量混淆；多端口并发数和 data 排序必须对应设计规范。

以下说明以随包 SVA 实现为重点。复位后的首次有效采样、历史状态有效位以及 generate 条件会影响检查起点；属性原文与完整源码可在本页下方对照。

2. 完整参数表

按 wrapper 声明顺序列出。默认表达式逐字取自源码；宏的最终值可被编译选项或用户头文件覆盖。标为内部/派生参数的条目不建议手动覆盖。

参数源码默认值作用与配置注意
severity_level`OVL_SEVERITY_DEFAULT失败报告的严重级别：OVL_FATAL、OVL_ERROR、OVL_WARNING、OVL_INFO；不是改变逻辑正确性的开关。
width1被检查数据/向量的位宽；对于 arbiter 是通道数，对于 CRC 是输入分片位宽。
depth2FIFO/栈容量，以元素为单位。
enq_count2独立入队端口数量，对应 enq 有效位个数。
deq_count2独立出队端口数量，对应 deq 有效位个数。
preload_count0复位时参考队列预装的元素数。
pass_thru0FIFO：允许空队列同拍直通；memory_sync：配置同地址读写的直通/读旧值关系。
registered0FIFO 满时同拍出队与入队的处理配置；与输出是否简单打一拍不是同一个参数。
high_water_mark0用于高水位覆盖/统计的阈值，不是替代 full 的 almost_full 输出端口。
enq_latency0入队控制到有效入队数据的周期延迟。
deq_latency0出队控制到有效出队数据的周期延迟。
value_check01 开启参考数据一致性检查，0 不做数据值比较；FIFO 与 memory 的默认值不同。
full_check01 检查 full 与参考占用量一致；multiport_fifo 默认 0。
empty_check01 检查 empty 与参考占用量一致；multiport_fifo 默认 0。
property_type`OVL_PROPERTY_DEFAULT选择 OVL_ASSERT、OVL_ASSUME、OVL_IGNORE 或二态变体；只有支持的后端才把 ASSUME 实现为形式约束。不要把 DUT 要求改为 assume 来消除失败。
msg`OVL_MSG_DEFAULT实例的诊断文本，建议包含被检查接口与需求名称。
coverage_level`OVL_COVER_DEFAULT覆盖层级位掩码；NONE=0、SANITY=1、BASIC=2、CORNER=4、STATISTIC=8、ALL=15。同时受 OVL_COVER_ON 控制。
clock_edge`OVL_CLOCK_EDGE_DEFAULTchecker 的时钟有效沿：OVL_POSEDGE、OVL_NEGEDGE 等；各后端支持情况需核对。
reset_polarity`OVL_RESET_POLARITY_DEFAULT复位有效电平：OVL_ACTIVE_LOW 或 OVL_ACTIVE_HIGH；不要因端口名为 reset 就默认高有效。
gating_type`OVL_GATING_TYPE_DEFAULTOVL_GATE_CLOCK 暂停时钟采样；OVL_GATE_RESET 用 enable 参与复位；OVL_NONE 不使用门控。暂停与清空历史不是同一语义。
assert_name"ASSERT_MULTIPORT_FIFO"内部诊断标识。源码注明不应修改。

3. 完整端口表

端口方向位宽表达式连接含义
clockinput1 bit采样时钟；有效沿由 clock_edge 决定。
resetinput1 bitchecker 复位输入；有效电平由 reset_polarity 决定。
enableinput1 bitOVL V2 门控输入，意义由 gating_type 决定；不一定只是 disable iff。
fullinput1 bitDUT 的满标志，用于与参考状态比较。
emptyinput1 bitDUT 的空标志，用于与参考状态比较。
enqinput[enq_count-1 : 0]FIFO 入队事件；多端口版本为有效位掩码。
deqinput[deq_count-1 : 0]FIFO 出队事件；多端口版本为有效位掩码。
enq_datainput[enq_count*width-1:0]按入队延迟对齐的数据，多端口时按低位端口先入顺序拼接。
deq_datainput[deq_count*width-1:0]按出队延迟对齐的数据，多端口时按低位端口先出顺序拼接。
preloadinput[(preload_count?(preload_count*width):1) -1:0]复位预装数据的拼接列表，低位元素先入队。
fireoutput[`OVL_FIRE_WIDTH-1 : 0]事件汇总输出；部分 wrapper 在 SVA 分支将其绑零，见本页实现提示。

4. 合法与违例场景

合法 / 期望覆盖场景

同拍端口0入 A、端口1入 B，按 A、B 顺序读出。

违例 / 覆盖缺口场景

数据检查开启后读出顺序颠倒。

5. Formal 接入与判读

不要将位掩码与 fifo_index 的二进制数量混淆；多端口并发数和 data 排序必须对应设计规范。

  • 验证 DUT 的要求使用 OVL_ASSERT；只有外部环境协议才适合作为 OVL_ASSUME。先检查 elaboration 后生成的属性数量与类型。
  • 复位应初始化 checker 的历史状态和参考模型；不要永久拉住复位或 enable=0。确认触发事件可达，避免 antecedent 永远为假的空证明。
  • 将安全断言结果、超时/未决结果与 cover 可达性分别记录。仿真跑过若干波形不等于形式证明。

参考队列/存储器会扩大状态空间。先使用小 depth、短数据宽度验证接线，再扩大参数；如采用任意地址/任意数据抽象，需单独证明抽象保持原需求，不能仅减少被检查的数据。

此 wrapper 的 SVA 分支将 fire 绑为 0。不能用 fire==0 证明检查通过；必须读取工具中的原生 assert/assume/cover 结果。

更多复位、门控、X/Z 与编译宏说明见 公共接入指南。本页没有声称所有配置均在 VC Formal 上经过编译或证明。

6. 属性、诊断与覆盖

下面是源码中的命名 property 定义，包含宏分支；同名属性可在互斥 generate 分支中出现。它们不是“全部同时启用”的断言清单。实际启用条件、参考状态更新及 assert/assume 实例请看完整源码。

OVL_MULTIPORT_FIFO_DEQUEUE_CHECK_P
property OVL_MULTIPORT_FIFO_DEQUEUE_CHECK_P;
  @(posedge  clk)
    disable iff (`OVL_RESET_SIGNAL != 1'b1)
      (pass_thru== 0)?($countones(deq_lat) <= volume) :($countones(deq_lat) <= volume+total_enq);
  endproperty
OVL_MULTIPORT_FIFO_ENQUEUE_CHECK_P
property OVL_MULTIPORT_FIFO_ENQUEUE_CHECK_P;
  @(posedge  clk)
    disable iff (`OVL_RESET_SIGNAL != 1'b1)
      (registered== 0)?($countones(enq_lat) <= depth-volume) :($countones(enq_lat) <= depth-(volume-total_deq));
  endproperty
OVL_MULTIPORT_FIFO_FULL_CHECK_P
property OVL_MULTIPORT_FIFO_FULL_CHECK_P;
  @(posedge  clk)
    disable iff (`OVL_RESET_SIGNAL != 1'b1)
      ((full && (volume == depth)) or (!full && (volume != depth)));
  endproperty
OVL_MULTIPORT_FIFO_EMPTY_CHECK_P
property OVL_MULTIPORT_FIFO_EMPTY_CHECK_P;
  @(posedge  clk)
    disable iff (`OVL_RESET_SIGNAL != 1'b1)
      ((empty && (volume == 0)) or (!empty && (volume != 0)));
  endproperty
OVL_MULTIPORT_FIFO_VALUE_CHECK_P
property OVL_MULTIPORT_FIFO_VALUE_CHECK_P(expected_deq_p,expected_deq_data_p,deq_data_p);
  @(posedge  clk)
    disable iff (`OVL_RESET_SIGNAL != 1'b1)
      (expected_deq_p && !enq_fired && !deq_fired[1]) |-> expected_deq_data_p == deq_data_p;
  endproperty
OVL_MULTIPORT_FIFO_XZ_ON_ENQ_P
property OVL_MULTIPORT_FIFO_XZ_ON_ENQ_P;
  @(posedge  clk)
    disable iff (`OVL_RESET_SIGNAL != 1'b1)
      (!($isunknown(enq)));
  endproperty
OVL_MULTIPORT_FIFO_XZ_ON_DEQ_P
property OVL_MULTIPORT_FIFO_XZ_ON_DEQ_P;
  @(posedge  clk)
    disable iff (`OVL_RESET_SIGNAL != 1'b1)
      (!($isunknown(deq)));
  endproperty
OVL_MULTIPORT_FIFO_XZ_ON_FULL_P
property OVL_MULTIPORT_FIFO_XZ_ON_FULL_P;
  @(posedge  clk)
    disable iff (`OVL_RESET_SIGNAL != 1'b1)
      (!($isunknown(full)));
  endproperty
OVL_MULTIPORT_FIFO_XZ_ON_EMPTY_P
property OVL_MULTIPORT_FIFO_XZ_ON_EMPTY_P;
  @(posedge  clk)
    disable iff (`OVL_RESET_SIGNAL != 1'b1)
      (!($isunknown(empty)));
  endproperty
OVL_MULTIPORT_FIFO_XZ_ON_ENQ_DATA_P
property OVL_MULTIPORT_FIFO_XZ_ON_ENQ_DATA_P(enq_p,enq_data_p);
  @(posedge  clk)
    disable iff (`OVL_RESET_SIGNAL != 1'b1)
     enq_p |-> (!($isunknown(enq_data_p)));
  endproperty

  • Illegal value for enq_count parameter which must not be greater than the depth

  • A dequeue occurred while the FIFO was empty
  • While the FIFO was empty, a dequeue occurred without an enqueue in the same cycle
  • An enqueue occurred while the FIFO was full
  • while the FIFO was full, an enqueue occurred without a dequeue in the same cycle
  • The FIFO was not full when the full signal was asserted
  • The full signal was not asserted when the FIFO was full
  • The FIFO was not empty when the empty signal was asserted
  • The empty signal was not asserted when the FIFO was empty
  • Dequeued FIFO value did not equal the corresponding enqueued value

  • deq contains X or Z
