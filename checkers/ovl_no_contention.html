ovl_no_contention — 总线争用与空闲间隔

位编码、互斥与数据完整性 OVL V2 接口

检查 driver_enables 不允许多驱动，并按配置检查总线未知值和 quiet 间隔。

语义参数端口例子FormalSVA 属性来源

1. 检查语义与触发时机

min_quiet/max_quiet 限制连续没有驱动的周期；默认两者为 0 时不允许无驱动周期，并非仅禁止争用。允许驱动时总线应无 X/Z。

对二态 formal，驱动互斥仍可检查，但电气争用、Z 与 X 语义不能自动保留。

以下说明以随包 SVA 实现为重点。复位后的首次有效采样、历史状态有效位以及 generate 条件会影响检查起点；属性原文与完整源码可在本页下方对照。

2. 完整参数表

按 wrapper 声明顺序列出。默认表达式逐字取自源码；宏的最终值可被编译选项或用户头文件覆盖。标为内部/派生参数的条目不建议手动覆盖。

参数源码默认值作用与配置注意
severity_level`OVL_SEVERITY_DEFAULT失败报告的严重级别：OVL_FATAL、OVL_ERROR、OVL_WARNING、OVL_INFO；不是改变逻辑正确性的开关。
min_quiet0总线无驱动间隔的最短周期数。
max_quiet0总线无驱动间隔的最长周期数；与 min_quiet 的组合决定 0 的含义。
num_drivers2driver_enables 的位数，即总线潜在驱动源个数。
width2被检查数据/向量的位宽；对于 arbiter 是通道数，对于 CRC 是输入分片位宽。
property_type`OVL_PROPERTY_DEFAULT选择 OVL_ASSERT、OVL_ASSUME、OVL_IGNORE 或二态变体；只有支持的后端才把 ASSUME 实现为形式约束。不要把 DUT 要求改为 assume 来消除失败。
msg`OVL_MSG_DEFAULT实例的诊断文本，建议包含被检查接口与需求名称。
coverage_level`OVL_COVER_DEFAULT覆盖层级位掩码；NONE=0、SANITY=1、BASIC=2、CORNER=4、STATISTIC=8、ALL=15。同时受 OVL_COVER_ON 控制。
clock_edge`OVL_CLOCK_EDGE_DEFAULTchecker 的时钟有效沿：OVL_POSEDGE、OVL_NEGEDGE 等；各后端支持情况需核对。
reset_polarity`OVL_RESET_POLARITY_DEFAULT复位有效电平：OVL_ACTIVE_LOW 或 OVL_ACTIVE_HIGH；不要因端口名为 reset 就默认高有效。
gating_type`OVL_GATING_TYPE_DEFAULTOVL_GATE_CLOCK 暂停时钟采样；OVL_GATE_RESET 用 enable 参与复位；OVL_NONE 不使用门控。暂停与清空历史不是同一语义。
assert_name"OVL_NO_CONTENTION"内部诊断标识。源码注明不应修改。

4. 合法与违例场景

合法 / 期望覆盖场景

min_quiet=1、max_quiet=2 时，一路驱动与一拍空闲交替。

违例 / 覆盖缺口场景

两个 driver_enables 同时为 1，或空闲长度越界。

示例中的周期指 checker 的有效采样沿；“变化”通常指相邻采样值变化。场景是语义说明，不代表下面保留默认参数的模板已配置成该场景。

命名参数 / 命名端口连接模板

这是接线片段，不是独立可运行的 testbench。需声明并驱动信号，设置实际宽度、复位极性、延迟及检查开关，再将 wrapper 加入编译列表。下载 SV 模板。

5. Formal 接入与判读

对二态 formal，驱动互斥仍可检查，但电气争用、Z 与 X 语义不能自动保留。

  • 验证 DUT 的要求使用 OVL_ASSERT；只有外部环境协议才适合作为 OVL_ASSUME。先检查 elaboration 后生成的属性数量与类型。
  • 复位应初始化 checker 的历史状态和参考模型；不要永久拉住复位或 enable=0。确认触发事件可达，避免 antecedent 永远为假的空证明。
  • 将安全断言结果、超时/未决结果与 cover 可达性分别记录。仿真跑过若干波形不等于形式证明。

此 wrapper 的 SVA 分支将 fire 绑为 0。不能用 fire==0 证明检查通过；必须读取工具中的原生 assert/assume/cover 结果。

更多复位、门控、X/Z 与编译宏说明见 公共接入指南。本页没有声称所有配置均在 VC Formal 上经过编译或证明。

6. 属性、诊断与覆盖

下面是源码中的命名 property 定义，包含宏分支；同名属性可在互斥 generate 分支中出现。它们不是“全部同时启用”的断言清单。实际启用条件、参考状态更新及 assert/assume 实例请看完整源码。

OVL_NO_CONTENTION_SINGLE_DRIVER_P
property OVL_NO_CONTENTION_SINGLE_DRIVER_P;
    @(posedge clk)
      disable iff (`OVL_RESET_SIGNAL != 1'b1)
        ($countones( driver_enables) <= 1);
  endproperty
OVL_NO_CONTENTION_NO_XZ_P
property OVL_NO_CONTENTION_NO_XZ_P;
    @(posedge clk)
      disable iff(`OVL_RESET_SIGNAL != 1'b1)
       (driver_enables != 0) |-> !($isunknown(test_expr));
  endproperty
OVL_NO_CONTENTION_QUIET_CASE1_P
property OVL_NO_CONTENTION_QUIET_CASE1_P;
    @(posedge clk)
      disable iff(`OVL_RESET_SIGNAL != 1'b1)
        ($countones(driver_enables) == 1);
  endproperty
OVL_NO_CONTENTION_QUIET_CASE2_P
property OVL_NO_CONTENTION_QUIET_CASE2_P;
    @(posedge clk)
      disable iff(`OVL_RESET_SIGNAL != 1'b1)
        (($past(driver_enables) != 0 || sva_checker_time_0) &&
         (driver_enables == 0)) |->
             (driver_enables == 0)[*1:max_quiet > 0 ? max_quiet : 1 ]
                ##1 ($countones(driver_enables) == 1);
  endproperty
OVL_NO_CONTENTION_QUIET_CASE3_P
property OVL_NO_CONTENTION_QUIET_CASE3_P;
    @(posedge clk)
      disable iff(`OVL_RESET_SIGNAL != 1'b1)
        (($past(driver_enables) != 0 || sva_checker_time_0) &&
               (driver_enables == 0)) |->
        (driver_enables == 0)[*min_quiet:max_quiet < min_quiet ? min_quiet : max_quiet]
          ##1 ($countones(driver_enables) == 1);
  endproperty
OVL_NO_CONTENTION_QUIET_CASE4_P
property OVL_NO_CONTENTION_QUIET_CASE4_P;
    @(posedge clk)
      disable iff(`OVL_RESET_SIGNAL != 1'b1)
        (($past(driver_enables) != 0 || sva_checker_time_0) &&
               (driver_enables == 0)) |->
          (driver_enables == 0)[*min_quiet];
  endproperty
OVL_NO_CONTENTION_XZ_ON_DRIVER_ENABLES_P
property OVL_NO_CONTENTION_XZ_ON_DRIVER_ENABLES_P;
    @(posedge clk)
    disable iff (`OVL_RESET_SIGNAL != 1'b1)
    (!($isunknown(driver_enables)));
    endproperty

原始失败诊断文本

以下文本便于与工具报告交叉查找，触发条件见上面的对应属性和源码分支。

  • More than 1 drivers are enabled
  • when at least 1 driver is enabled bus is going to X or Z
  • test expr (bus) was not quiet minimum for min_quiet and maximum for max_quiet cycles
  • driver_enables contains X or Z

  • cover_driver_enable
  • cover_quiet_time_equal_to_max_quiet
  • cover_quiet_time_equal_to_min_quiet
