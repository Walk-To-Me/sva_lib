ovl_stack — LIFO 栈 scoreboard

FIFO、栈与存储器 OVL V2 接口

内部参考栈检查后入先出数据、满空标志和容量边界。

语义参数端口例子FormalSVA 属性来源

1. 检查语义与触发时机

push_latency/pop_latency 对齐操作与数据。本 checker 将同一有效操作拍的 push 与 pop 并发视为违例。

即使 DUT 定义了合法的同拍替换行为，也不能直接用此 checker 声称兼容；需要适配或另写属性。

以下说明以随包 SVA 实现为重点。复位后的首次有效采样、历史状态有效位以及 generate 条件会影响检查起点；属性原文与完整源码可在本页下方对照。

2. 完整参数表

按 wrapper 声明顺序列出。默认表达式逐字取自源码；宏的最终值可被编译选项或用户头文件覆盖。标为内部/派生参数的条目不建议手动覆盖。

参数源码默认值作用与配置注意
severity_level`OVL_SEVERITY_DEFAULT失败报告的严重级别：OVL_FATAL、OVL_ERROR、OVL_WARNING、OVL_INFO；不是改变逻辑正确性的开关。
depth2FIFO/栈容量，以元素为单位。
width1被检查数据/向量的位宽；对于 arbiter 是通道数，对于 CRC 是输入分片位宽。
high_water_mark0用于高水位覆盖/统计的阈值，不是替代 full 的 almost_full 输出端口。
push_latency0push 控制到实际入栈数据操作的周期延迟。
pop_latency0pop 控制到实际出栈数据操作的周期延迟。
property_type`OVL_PROPERTY_DEFAULT选择 OVL_ASSERT、OVL_ASSUME、OVL_IGNORE 或二态变体；只有支持的后端才把 ASSUME 实现为形式约束。不要把 DUT 要求改为 assume 来消除失败。
msg`OVL_MSG_DEFAULT实例的诊断文本，建议包含被检查接口与需求名称。
coverage_level`OVL_COVER_DEFAULT覆盖层级位掩码；NONE=0、SANITY=1、BASIC=2、CORNER=4、STATISTIC=8、ALL=15。同时受 OVL_COVER_ON 控制。
clock_edge`OVL_CLOCK_EDGE_DEFAULTchecker 的时钟有效沿：OVL_POSEDGE、OVL_NEGEDGE 等；各后端支持情况需核对。
reset_polarity`OVL_RESET_POLARITY_DEFAULT复位有效电平：OVL_ACTIVE_LOW 或 OVL_ACTIVE_HIGH；不要因端口名为 reset 就默认高有效。
gating_type`OVL_GATING_TYPE_DEFAULTOVL_GATE_CLOCK 暂停时钟采样；OVL_GATE_RESET 用 enable 参与复位；OVL_NONE 不使用门控。暂停与清空历史不是同一语义。
assert_name"OVL_STACK"内部诊断标识。源码注明不应修改。

端口方向位宽表达式连接含义

resetinput1 bitchecker 复位输入；有效电平由 reset_polarity 决定。
enableinput1 bitOVL V2 门控输入，意义由 gating_type 决定；不一定只是 disable iff。

4. 合法与违例场景

合法 / 期望覆盖场景

push A、push B、pop B、pop A。

违例 / 覆盖缺口场景

先 pop A，或空栈 pop，或同有效拍同时 push/pop。

示例中的周期指 checker 的有效采样沿；“变化”通常指相邻采样值变化。场景是语义说明，不代表下面保留默认参数的模板已配置成该场景。

5. Formal 接入与判读

即使 DUT 定义了合法的同拍替换行为，也不能直接用此 checker 声称兼容；需要适配或另写属性。

  • 验证 DUT 的要求使用 OVL_ASSERT；只有外部环境协议才适合作为 OVL_ASSUME。先检查 elaboration 后生成的属性数量与类型。
  • 复位应初始化 checker 的历史状态和参考模型；不要永久拉住复位或 enable=0。确认触发事件可达，避免 antecedent 永远为假的空证明。
  • 将安全断言结果、超时/未决结果与 cover 可达性分别记录。仿真跑过若干波形不等于形式证明。

参考队列/存储器会扩大状态空间。先使用小 depth、短数据宽度验证接线，再扩大参数；如采用任意地址/任意数据抽象，需单独证明抽象保持原需求，不能仅减少被检查的数据。

此 wrapper 的 SVA 分支将 fire 绑为 0。不能用 fire==0 证明检查通过；必须读取工具中的原生 assert/assume/cover 结果。

更多复位、门控、X/Z 与编译宏说明见 公共接入指南。本页没有声称所有配置均在 VC Formal 上经过编译或证明。

6. 属性、诊断与覆盖

下面是源码中的命名 property 定义，包含宏分支；同名属性可在互斥 generate 分支中出现。它们不是“全部同时启用”的断言清单。实际启用条件、参考状态更新及 assert/assume 实例请看完整源码。

OVL_STACK_OVERFLOW_P
property OVL_STACK_OVERFLOW_P;
    @( posedge clk)
      disable iff( `OVL_RESET_SIGNAL != 1'b1)
        not((sva_v_stack_ptr >= depth) &&
          sva_v_deferred_push &&
          (!sva_v_deferred_pop));
  endproperty
OVL_STACK_UNDERFLOW_P
property OVL_STACK_UNDERFLOW_P;
    @( posedge clk)
      disable iff( `OVL_RESET_SIGNAL != 1'b1)
        not((sva_v_stack_ptr == 0) &&
          (!sva_v_deferred_push) &&
          sva_v_deferred_pop );
  endproperty
OVL_STACK_VALUE_P
property OVL_STACK_VALUE_P;
    @( posedge clk)
      disable iff( `OVL_RESET_SIGNAL != 1'b1)
       (sva_v_deferred_pop && !sva_v_deferred_push && sva_v_stack_ptr > 0) |->
          (sva_w_data == pop_data );
  endproperty
OVL_STACK_PUSH_POP_P
property OVL_STACK_PUSH_POP_P;
    @( posedge clk)
      disable iff( `OVL_RESET_SIGNAL != 1'b1)
        not( sva_v_deferred_push &&
             sva_v_deferred_pop);
  endproperty
OVL_STACK_EMPTY_P
property OVL_STACK_EMPTY_P;
    @( posedge clk)
      disable iff( `OVL_RESET_SIGNAL != 1'b1)
        not (( sva_v_stack_ptr == 0 && empty == 1'b0) ||
         ( sva_v_stack_ptr != 0 && empty == 1'b1));
  endproperty
OVL_STACK_FULL_P
property OVL_STACK_FULL_P;
    @( posedge clk)
      disable iff( `OVL_RESET_SIGNAL != 1'b1)
        not (( sva_v_stack_ptr == depth && full == 1'b0) ||
         ( sva_v_stack_ptr != depth && full == 1'b1));
  endproperty

原始失败诊断文本

以下文本便于与工具报告交叉查找，触发条件见上面的对应属性和源码分支。

  • Data is pushed into the stack when the stack is full
  • Data is poped from the stack when the stack is empty
  • Data poped from the stack is not the same as the data pushed into the stack
  • push and pop are asserted simultaneously
  • Empty flag is not asserted when the stack is empty
  • Empty flag is asserted when the stack is not empty
  • Full flag is not asserted when the stack is full
  • Full flag is asserted when the stack is not full
  • push contains X or Z
  • pop contains X or Z
  • full flag contains X or Z
  • empty flag contains X or Z
  • push_data contains X or Z
  • pop_data contains X or Z
