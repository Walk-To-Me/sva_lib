assert_unchange — 限时保持稳定

周期、窗口与稳定性 旧版接口

start_event 启动后，要求接下来 num_cks 拍保持 test_expr 稳定。

语义参数端口例子FormalSVA 属性来源

这是保留兼容用途的旧接口，不是新增一种检查语义。使用旧版专属端口表和模板；不能只把模块名称替换为 ovl_*。查看对应 V2 说明。旧接口复位由 std_ovl_defines.h 宏选择，未暴露 V2 的 clock_edge/reset_polarity/gating_type 参数。

1. 检查语义与触发时机

启动拍建立参考；后续每个采样沿检查变化。action_on_new_start 决定忙碌期间新的 start 如何处理。

重启模式在重启点可换基准；若目标是不允许任何变化，应仔细选择策略。

以下说明以随包 SVA 实现为重点。复位后的首次有效采样、历史状态有效位以及 generate 条件会影响检查起点；属性原文与完整源码可在本页下方对照。

2. 完整参数表

按 wrapper 声明顺序列出。默认表达式逐字取自源码；宏的最终值可被编译选项或用户头文件覆盖。标为内部/派生参数的条目不建议手动覆盖。

参数源码默认值作用与配置注意
severity_level`OVL_SEVERITY_DEFAULT失败报告的严重级别：OVL_FATAL、OVL_ERROR、OVL_WARNING、OVL_INFO；不是改变逻辑正确性的开关。
width1被检查数据/向量的位宽；对于 arbiter 是通道数，对于 CRC 是输入分片位宽。
num_cks1检查周期数或精确延迟；cycle_sequence 中同时决定事件向量长度。
action_on_new_start`OVL_ACTION_ON_NEW_START_DEFAULTIGNORE_NEW_START 忽略忙碌期间新启动；RESET_ON_NEW_START 重启；ERROR_ON_NEW_START 对新启动报错。各 checker 在边界拍的处理见源代码。
property_type`OVL_PROPERTY_DEFAULT选择 OVL_ASSERT、OVL_ASSUME、OVL_IGNORE 或二态变体；只有支持的后端才把 ASSUME 实现为形式约束。不要把 DUT 要求改为 assume 来消除失败。
msg`OVL_MSG_DEFAULT实例的诊断文本，建议包含被检查接口与需求名称。
coverage_level`OVL_COVER_DEFAULT覆盖层级位掩码；NONE=0、SANITY=1、BASIC=2、CORNER=4、STATISTIC=8、ALL=15。同时受 OVL_COVER_ON 控制。
assert_name"ASSERT_UNCHANGE"内部诊断标识。源码注明不应修改。

4. 合法与违例场景

合法 / 期望覆盖场景

num_cks=3，启动为 A，随后 A、A、A。

违例 / 覆盖缺口场景

检查窗口内任一拍变成 B。

示例中的周期指 checker 的有效采样沿；“变化”通常指相邻采样值变化。场景是语义说明，不代表下面保留默认参数的模板已配置成该场景。

5. Formal 接入与判读

重启模式在重启点可换基准；若目标是不允许任何变化，应仔细选择策略。

  • 验证 DUT 的要求使用 OVL_ASSERT；只有外部环境协议才适合作为 OVL_ASSUME。先检查 elaboration 后生成的属性数量与类型。
  • 复位应初始化 checker 的历史状态和参考模型；不要永久拉住复位或 enable=0。确认触发事件可达，避免 antecedent 永远为假的空证明。
  • 将安全断言结果、超时/未决结果与 cover 可达性分别记录。仿真跑过若干波形不等于形式证明。

更多复位、门控、X/Z 与编译宏说明见 公共接入指南。本页没有声称所有配置均在 VC Formal 上经过编译或证明。

6. 属性、诊断与覆盖

下面是源码中的命名 property 定义，包含宏分支；同名属性可在互斥 generate 分支中出现。它们不是“全部同时启用”的断言清单。实际启用条件、参考状态更新及 assert/assume 实例请看完整源码。

ASSERT_UNCHANGE_P
property ASSERT_UNCHANGE_P;
  @(posedge clk)
  disable iff (`OVL_RESET_SIGNAL != 1'b1)
  (start_event && !window) |=> ($stable(test_expr)[*num_cks]);
  endproperty
ASSERT_UNCHANGE_RESET_ON_START_P
property ASSERT_UNCHANGE_RESET_ON_START_P;
  @(posedge clk)
  disable iff (`OVL_RESET_SIGNAL != 1'b1)
  (start_event) |=> (
                      ($stable(test_expr)[*num_cks])
	              or
                      ($stable(test_expr)[*0:num_cks-1] ##1 start_event)
	            );
  endproperty
ASSERT_UNCHANGE_ERR_ON_START_P
property ASSERT_UNCHANGE_ERR_ON_START_P;
  @(posedge clk)
  disable iff (`OVL_RESET_SIGNAL != 1'b1)
  window |-> !start_event;
  endproperty
ASSERT_UNCHANGE_XZ_ON_START_P
property ASSERT_UNCHANGE_XZ_ON_START_P;
  @(posedge clk)
  disable iff (`OVL_RESET_SIGNAL != 1'b1)
  !(window) |-> (!($isunknown(start_event)));
  endproperty
ASSERT_UNCHANGE_XZ_ON_NEW_START_P
property ASSERT_UNCHANGE_XZ_ON_NEW_START_P;
  @(posedge clk)
  disable iff (`OVL_RESET_SIGNAL != 1'b1)
  (window) |-> (!($isunknown(start_event)));
  endproperty
ASSERT_UNCHANGE_XZ_ON_TEST_EXPR_P
property ASSERT_UNCHANGE_XZ_ON_TEST_EXPR_P;
  @(posedge clk)
  disable iff (`OVL_RESET_SIGNAL != 1'b1)
  (window || start_event) |-> (!($isunknown(test_expr)));
  endproperty

以下文本便于与工具报告交叉查找，触发条件见上面的对应属性和源码分支。
